# Skill: Frontend & UX (Symfony UX)

## Fokus
- Nutzung von Symfony UX Komponenten (Live Components).
- Asset-Management mit AssetMapper/Encore.
- Barrierefreiheit und responsives Design.
- Effiziente Twig-Templates und Komponenten-Struktur.

## Regeln
- Bevorzuge Komponenten über komplexe Controller-Logik.
- Achte auf schlanke JS-Payloads.
- Nutze Twig-Components zur Wiederverwendbarkeit.
- UX vor Over-Engineering: Halte Interaktionen einfach und intuitiv.

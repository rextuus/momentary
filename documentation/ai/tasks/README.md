# AI Tasks

Hier werden Tasks definiert, an denen die KI arbeiten soll.

## Wie starte ich einen Task?

Um einen Task zu starten, sag mir einfach:
> "Arbeite am Task `[dateiname.md]` mit folgenden Skills: `[skill-name], ...`."

Ich werde dann den Task-Plan laden und mich auf die Skills fokussieren.

## Vorlage für einen Task (`task-name.md`)

```markdown
# [Task-Titel]
Status: [OPEN|IN_PROGRESS|DONE]
Erstellt am: [Datum]

## Beschreibung
[Detaillierte Beschreibung, was zu tun ist]

## Plan
1. [...]
2. [...]

## Referenzen
- [...]
```
